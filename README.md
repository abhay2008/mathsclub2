A suite of mathematical problem solvers, proof derivations, and algorithmic implementations covering **Euclid's Division Lemma**, **Systems of Linear Equations**, and **Matrix Determinants**.

---

## 📚 Included Modules

- **`LinearEquations.py`:** Computational solver for multi-variable linear equation systems.
- **`EuclidDivisionLemmaAlgorithm`:** Number theory algorithm for Greatest Common Divisor (GCD) extraction.
- **`determinants.MD` & `derivation.MD`:** Rigorous algebraic proofs and step-by-step matrix reduction rules.

---

## 🚀 Usage

```bash
python LinearEquations.py
```
